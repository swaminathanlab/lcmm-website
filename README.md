# LCMM website

Website of the Laboratory of Cell and Molecular Mechanobiology (Swaminathan lab), Lund University.

Built with [Zensical](https://zensical.org) (the Material for MkDocs successor) from YAML and
Markdown, on the same stack as the [Cell Migration Lab site](https://github.com/CellMigrationLab/website).
Every push to `main` rebuilds the site, and **publishing waits for your approval** in GitHub
(the `github-pages` environment). Pull requests get a downloadable preview
(Actions run → Artifacts → `site-preview`). **[PUBLISHING.md](PUBLISHING.md)** has the
step-by-step setup and everyday routine.

## What to edit

Edit the file on GitHub (pencil icon) and commit; the site rebuilds and waits for your approval before going live.

| Page / part | File |
| --- | --- |
| Lab name, headline, tagline, intro, header picture, contact, funding | `data/site.yaml` (`*word*` in the headline = italic accent) |
| Research themes (Research page + home cards; picture/video and tags per theme) | `data/research.yaml` |
| People and alumni | `data/people.yaml`, photos in `data/photos/<id>.jpg` |
| News | `data/news.yaml` |
| Image gallery (home page + /gallery/) | drop files in `data/gallery/`; captions and order in `data/gallery.yaml` |
| Publications | automatic (see below); corrections in `data/publications_overrides.yaml` |
| Join us | `content/join-us.md` |
| Extra text under the contact details | `content/contact.md` (optional) |
| Colours, fonts, layout | `docs/assets/stylesheets/lcmm.css` (accent colour: `--lc-accent`) |
| Top menu (order, names) | `nav:` in `mkdocs.yml` |
| Header picture and research-theme pictures | put the file in `data/gallery/`, name it in `site.yaml` (`hero_image`) or `research.yaml` (`media`) |

Pages in `docs/*.md` are generated by `scripts/build_pages.py`; don't edit them, they are overwritten.

## Publications

`.github/workflows/sync-publications.yml` runs every Monday. It searches Europe PMC for
everything on the PI's ORCID plus "Swaminathan V" papers with a Lund/NIH/UNC/lab-member footprint
and, if anything is new, opens a **pull request** for you to review; nothing is published until
you merge it and approve the deploy. Retracted papers are never listed. It never removes a
paper; to drop one (namesake, duplicate preprint) add its PubMed ID or DOI to `hide:` in
`data/publications_overrides.yaml`. Also there:

- `featured`: the papers shown on the home page
- `add`: papers Europe PMC does not index (book chapters, conference proceedings)
- `fix`: title or field corrections (PubMed strips superscripts, e.g. m6A)

When a preprint is published, both versions appear; hide the preprint.
Lab members' names are bolded in author lists using `pubmed_name` in `data/people.yaml`.
Run it by hand from the Actions tab (Sync publications → Run workflow).

## Run locally

```bash
pip install -r requirements.txt
python scripts/build_pages.py
zensical serve          # http://localhost:8000
```
